# Smart Pantry

## Project Overview

Smart Pantry is an Android application developed using Java and Android Studio.

The application assists users with:

- Pantry ingredient management
- Ingredient quantity tracking
- Recipe suggestions
- SQLite database integration

## Features Implemented

- Main Activity
- Add Ingredient Screen
- Edit Ingredient Screen
- Recipe Screen
- SQLite DatabaseHelper
- Ingredient Model
- Recipe Model

## Technologies Used

- Java
- Android Studio
- SQLite

## Challenges
